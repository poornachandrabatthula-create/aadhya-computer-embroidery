# Security Policy

## Reporting a security issue

Please do not publish suspected vulnerabilities, credentials, access tokens, or exploit details in a public issue.

For a private report, use GitHub's private vulnerability reporting for this repository when available. Include the affected page/file, a clear description of the issue, reproduction steps, and the potential impact.

## Security scope

This repository contains the public static website for Aadhya Computer Embroidery Works & Tailor. Do not include passwords, API keys, private customer information, or other secrets in the repository.

## Response

Security reports will be reviewed and remediated as quickly as practical. Any exposed credential should be treated as compromised and rotated immediately.
